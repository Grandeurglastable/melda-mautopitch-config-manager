## 🚀 Features

| **Feature** | **Description** |
|:---|:---|
| **Config Library** | Save MAutoPitch configurations per vocal genre and style |
| **Scale Settings** | Document scale and key settings used per session or project |
| **Creative Presets** | Track T-Pain style and creative pitch effect configurations |
| **Formant Notes** | Log formant shift settings used for vocal character presets |
